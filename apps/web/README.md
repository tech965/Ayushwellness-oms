# AyushWellness OMS — Web

Next.js (App Router) frontend. See the repo root
[`README.md`](../../README.md) and [`docs/architecture/frontend.md`](../../docs/architecture/frontend.md)
for the full picture; this file only covers commands local to this
package.

```bash
npm install
npm run dev          # http://localhost:3000
npm run build
npm run lint
npm run typecheck
npm run test
npm run format
```

Requires `NEXT_PUBLIC_API_URL` — copy `.env.example` to `.env.local`.
